# MiraStaff

Staff tooling for Paper 1.21.11 / Java 21.

## Current release

**v0.1.0**

Direct download:
https://github.com/FiveSOCE/Mira-Staff/releases/download/v0.1.0/MiraStaff-0.1.0.jar

All releases:
https://github.com/FiveSOCE/Mira-Staff/releases

## Features

- Staff mode
- Vanish with staff visibility permission
- Freeze/unfreeze
- Frozen-disconnect alerts
- Live inventory inspection
- Staff teleport
- Staff chat
- Public Bukkit ServicesManager API
- Does not take control of player flight; MiraFly remains the single flight authority

## Commands

- `/staff`
- `/vanish`
- `/freeze <player>`
- `/inspect <player>`
- `/stafftp <player>`
- `/staffchat <message>`

## Build

`./gradlew build`

Output: `build/libs/MiraStaff-0.1.0.jar`
